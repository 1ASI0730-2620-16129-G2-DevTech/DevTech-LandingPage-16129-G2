# WashTrack - Landing Page

WashTrack es una landing page de una solución digital para lavanderías. El proyecto busca mejorar la experiencia de los clientes, mostrando los servicios disponibles, el seguimiento de los pedidos y los beneficios de la membresía Wash VIP.

## Características

* Diseño adaptable para computadoras, tablets y celulares.
* Menú hamburguesa para dispositivos móviles. (RESPONSIVE)
* Seguimiento del estado de los pedidos mediante una línea de tiempo.
* Información sobre los servicios de lavandería.
* Sección de membresía Wash VIP.
* Formulario y sección de contacto.

## Tecnologías utilizadas
HTML
CSS
JavaScript
